KNOWN LIMITS / OBSERVATIONS
 - Backspace only edits the run being typed: selection delete, cut, delete-line tools and "move cursor then backspace" are not followed. Bangla deletes are followed per code point.
 - Entries are runs: Enter, field / app change, 2 min idle, 500 chars end a run. Voice typing (system keyboard) is not captured.
 - The page shows a snapshot: new typing in another app is visible after you close and reopen the page (the page is in front, so nothing is typed meanwhile).
 - HistCard and the page both use HistStore.whenLoaded (one callback slot): the page overwrites the card's callback; the card refreshes on page close instead.
 - Rotating the phone with the page open recreates the Activity; the dialog is closed with it (an Android "leaked window" log line is possible, no crash expected). NOT tested.
 - Stale text found, NOT changed: PrivacyInfo.permissionLines says password fields record no clipboard history, but v0.18.12 (clip_pwd, default ON) saves copies made in password fields. Ask the owner before changing the wording or the default.
