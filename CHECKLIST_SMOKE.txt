Use this FIRST after installing a new build. It touches every new thing of plan N once.
If all lines are OK, the long lists in CHECKLIST.txt (Z77 - Z84) are only needed when something looks wrong.
If a line fails, send: which line number + what you see (+ screenshot). One bug = one fix version.
Not tested on a phone by the builder: every line below is still [ ] until you tick it.
