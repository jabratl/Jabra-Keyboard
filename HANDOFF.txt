                           y/w after consonant = ya/ba-phala; "ng" before vowel = ঙ else ং; tiny AUTO list (valo, tomar, kono...).
                           NOT yet: ৎ, ঁ, ঃ, Bangla digits, dictionary autocorrect.
    SettingsActivity.kt    enable/choose keyboard, test box, Check for updates. Updater.kt = GitHub Releases updater
                           (stage 1: download apk + system installer; stage 2: open release page in browser).
  Prefs file "jabra": key "bangla" (boolean). Do not rename.
  Typing flow in Bangla mode: letters collect in buf -> setComposingText(Bangla) -> commit on space/punct/enter/switch.
  If engine throws: Latin letters are shown (fallback). Password/email/URL/number fields: always English.
  Test engine on a computer:
    java -m jdk.compiler/com.sun.tools.javac.Main -encoding UTF-8 -d out app/src/main/java/com/mgb/keyboard/phonetic/AvroPhonetic.java tools/AvroTest.java
