1. DECISION (which of the 4 styles, and why)
You listed: Inline Text, Overflow (kebab), Split Button, Ghost / Pill Select.
CHOSEN = ONE new part "PillSelect" (Ghost / Pill look + Inline Text look in Borderless theme). Per place:
 a) PillSelect  = every single choice that today is a chip row or a cycle button: Clipboard filter (All / Pinned / Text / Links / Numbers), sort, view, Vault folder + kind, Export scope + pack, Settings lists with 5+ options or long names.
    Why: the CURRENT value stays visible ("Newest v"), one control instead of 3-5 chips, ~40 dp high, works in every theme. A bare Inline Text is too small to hit (below the 40 dp MIN_TOUCH rule), so it is used only as the look in the Borderless theme (no fill, just text + v).
 b) Overflow (the existing "..." tray) = ACTIONS only (Manage, Deleted n, Export all, Clear). Never for choices: it hides the current state.
 c) Split Button = ONE place: select-mode bar "Paste v" (Paste = main tap, v = Paste 1 line / To Vault / Export). Nowhere else (not needed).
 d) Keep as they are: Switch rows (on/off), segments for 2-4 SHORT options (RowPlan.segmented rule), steppers (- value +), text rows, big action buttons.
Nothing is deleted: every option stays reachable, only the place changes. Safety: pref ui_pill (default ON) = OFF gives the old chips back (added in S2).

4. DESIGN RULES (found by audit; follow them, no new colours / fonts)
 - Colours only from JabraTokens / JabraThemes (never hard-coded), dark/light by isDark(p); selected = ACCENT family, pinned = gold border (clips), danger = DANGER, state is never colour alone (drawn tick for the current item, same as Details / Format chips).
 - Radius R_SM 9 for pills (same as keys in Jabra look); popup list R_MD 12. Spacing S1/S2/S3 = 4/8/12 dp, margin around panel buttons GAP 2 dp.
 - Text: keyboard panels T_BTN 12 sp via fs(); app pages T_BODY 14 / T_LABEL; notes T_NOTE 11. System font (no custom font). Labels may be long in Bangla: single line, ellipsize END, max width = 45% of the row.
 - Touch: min 40 dp high (PanelLayout.MIN_TOUCH, scaled by clip_btn_pct through sz()); pills in one row share width by weight.
 - Themes: Classic / Jabra look = soft pill (key colour, light stroke); Borderless = NO fill, text + v only (this is the "Inline Text" look); Custom = follow Theme studio like btn().
 - Icons: label + " v" through Glyphs.dress / Glyphs.relabel (icons_on pref OFF = plain text sign). A pill ALWAYS shows the current value, never a fixed word.
 - Popup in the keyboard: PopupWindow (non focusable) above or below the pill, kept on screen, max 6 visible rows then scroll, closes on pick / outside tap / panel change / Back. Row height 40 dp, current item ticked. If the popup cannot show (any Throwable): fallback = the pill CYCLES the value on tap (never a dead control).
 - Breakpoints: no CSS. Phones 360 dp wide are the minimum; landscape keeps the same rows (panel height is limited, so pills must not wrap to two lines); large font / clip_btn_pct 70-140 must not clip text.
 - Every new function: try { } catch (_: Throwable) { fallback }. No new permission, no storage format change, no network.
