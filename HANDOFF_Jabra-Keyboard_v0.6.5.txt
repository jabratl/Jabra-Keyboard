3) SENIOR-ENGINEER AUDIT (what was found; only ADD what is missing)
  PERFORMANCE (key-press path = MgbIme.key()/letter()/onLetter()/feedback()/onUpdateSelection()):
   F1 onUpdateSelection() -> autoCapUpdate() -> ic.getCursorCapsMode() runs on EVERY selection change = a synchronous
      cross-process call to the host app after almost every keystroke. Biggest lag risk on slow apps. (-> S2)
   F2 feedback() on every tap: getSystemService(VIBRATOR) each time + 2-3 SharedPreferences reads. (-> S1)
   F3 KeyPopup.touch() reads pref key_popup on every ACTION_DOWN; HintKeys.attach touch reads hint_on / lp_delay each DOWN;
      HintKeys.refresh() runs for 26 keys on every shift tap, each reading 3-4 prefs (~100 reads per Shift tap). (-> S1, S2)
   F4 Build cost (buildKeyboard): ~45 Buttons x (2 GradientDrawable + StateListDrawable + ~15 pref reads). Only matters at
      keyboard open / rotate / "ABC apply". Small win; do only if S1-S2 phone test still feels slow. (-> S3, optional)
   OK ALREADY (do not touch): backup runs on a background Thread, once per day, 1 int read on input start; stores load lazily;
      AtomicFile for big data; theme custom JSON parse is cached (ctCache); no timers/services; no new libraries.
   NOT adding: R8/minify (risk with updater/signing, cannot test), custom drawing View instead of Button (big rewrite, Rule 0),
      background services, WorkManager, any library.
  DESIGN:
   G1 Panels do not follow the keyboard theme: ClipboardFeature, ClipCards, FormatterFeature, VaultPanel, TextToolsPanel,
      ProfilePanel, HealthPanel have 0 references to JabraThemes (the theme only colours the keys + theme screens) -> in a
      dark theme the panels keep their own default buttons / hard-coded greys (not phone-verified how bad it looks). (-> S4-S8)
   G2 about 19 private copies of a btn()/pk() helper (ClipboardFeature, FormatterFeature, VaultPanel, TextToolsPanel, ProfilePanel,
      ThemeStudio, ToolbarPanel, ToolbarQuick, SizePrefs, TypingExtras, TypingPrefs, PadPanel, JabraExtras, SettingsGroups, DataPage, HealthPanel...). No shared tokens;
      hex colours scattered (#DDDDDD x17, #555555 x9, #222222 x9). (-> S4 shared kit, then migrate panel by panel)
   G3 App screen (SettingsActivity) is fixed Theme.DeviceDefault.Light = no dark mode. (-> S9 optional)
