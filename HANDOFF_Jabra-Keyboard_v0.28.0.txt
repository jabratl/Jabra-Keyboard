=== PART 1 (v0.24.0) - WHAT EXISTS ===
 typing/ReplaceEngine.java  PURE JAVA, never throws. run(text, find, with, opt, first, last) core; replaceAll / replaceFirst / replaceNth(n) / count. Result = out, count, changed, blank, err, hits (first 50, found + replacement). Opt = mode (MODE_TEXT 0 / WORD 1 / REGEX 2), matchCase, bangla, escapes; pack / unpack = pref rp_opt. TEXT / WORD quote the Find; WORD uses \p{L}\p{M}\p{N}_ look-around (no \b). REGEX = Java regex MULTILINE; With: $0 $& $1..$99 ${name} $$ \n \t \\ \U \L \E \u \l. Guard clock BUDGET_MS 400 per run; limits MAX_TEXT 100000, MAX_MATCHES 20000, MAX_OUT 300000. line() / info() = preview text helpers.

 Find / With texts live only in memory (never written to disk); only rp_opt is saved. Whole-field Replace = 2 taps + Undo (io.undoReplace). Field is read when the panel opens and after Replace / Undo / Sel / scope change.

=== PART 2 (v0.25.0) - WHAT EXISTS ===

Syntax = Formatter syntax: "find => with", "re: find => with", "del: text" (every LINE with the text is removed, built as a regex with Pattern.quote), "del-re: pattern", "# comment".
