HANDOFF - Jabra Keyboard - Clipboard limits - v0.49.0

WHAT: clipboard limits are bigger and adjustable.
  - Defaults: Recent 100 clips (was 40), pinned 50 (was 30), Add / Edit 20000 chars (was 2000), copied text 100000 chars (was 20000), Recent text budget 300000 chars (was 150000).
  - Settings > Clipboard & tools: "Clips kept in Recent" (pref clip_keep_n, 10-300) and "Longest copied text (k characters)" (pref clip_cap_k, 5-200).
  - ClipList.configure(unpinned, capture) sets the limits; ClipStore.applyLimits() calls it on init and before every add() / addCaptured().
  - Lowering a limit deletes nothing until the next copy. parse() accepts clips up to ClipList.CAPTURE_CEIL (200000), so a lower setting never drops saved clips.
  - Hard ceilings: UNPINNED_CEIL 300, CAPTURE_CEIL 200000, CHARS_CEIL 600000 (budget = max(300000, 3 x capture), capped).
