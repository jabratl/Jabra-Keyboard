Why this is simpler The pair list, the Never change list and the sets of a novel are one list. A pair is a row, a locked name is a row, topics are chips.

What you see before you tap Each row shows how many times it hits the text now. Rows with hits come first, rows with none fade.

Keeping a pair “Add pair” already saves it to the novel. No second step, no separate Save screen.
