Ki bodlalo

  • Search = shudhu ekta icon. Chaple oi row-e search field khule jay (X ba Esc dile abar icon). Sort / view / undo ek ⋯ menu-te. Alada filter pill row nai.
  • Filter = chhoto tab, pill na. Selected tab-er niche ekta line. Shob count dekhay.
  • Pinned = ek line-er chip strip. Section header nai. Chip chaple paste hoy. Row-ei sonar dag thake.
  • Ek clip = ek line, boro clip-e right-e chhoto ⌄ chaple khule jay (6 line porjonto). Age ar “Aa” format tag ek jaygay.
  • Swipe: daane = pin, baame = delete, tarpor niche Undo bar. Pin / x button-er jaygay lage na.
  • Tap = paste. Dhore rakho = select. Select korle shudhu ekta chhoto pill: Paste Aa, T (plain), Pin, Delete.
  • Image thumbnail ekta chhoto line-e, ager moto tap = paste.
