Find & Replace – ek screen, diff previewTry koro: Find / With e likho, match er upor tap kore skip koro, “Whole word” chip chap, Pairs e jao, Never change e naam rakho, field e mouse diye text select koro, Replace chap, Undo chap.

Field e text select koro = “Selection” scope. Click korle cursor boshe (From / To cursor er jonno).

Ki bodlalo (shob purano feature thake)

  • Ek screen. Ager moto alada main / typing / Sets / Recent / Never / Help / pair list view nai. Upore Find + With ek jaygay, Sel / Clip field er bhitore, majhkhane ⇄ swap. Sets, Recent, Never change, Help = ⋯ menu.
  • 5 ta step button → 1 ta. “Replace all / 1st / < / Skip / Replace this / Rest” er bodole ekta boro Replace 4 button. Kon match bad dibe? Preview te oi match e tap koro, se dotted hoye skip hobe, button hobe “Replace 3 of 4”. “Only first / Only this / From this on” = niche ⋯ menu te.
  • Diff preview. Ki jacche (lal, kata) → ki boshbe (shobuj) ek-i jaygay dekha jay. Result tab e shudhu final text. Count ar “2 of 4” navigation upore.
  • Mode + option = ek line chip. Text | Word | Regex, tarpor Aa, Keep, List (a | b | c), Smart, \n. Regex mode e List / Smart / \n lukiye jay (ager moto).
  • Scope = ek pill. Selection / Whole field / From cursor / To cursor. Whole field e Replace chaple lal hoye “Tap again to confirm”. Undo = ↶ 3 level, badge e koyta ache.

Notun (powerful) idea

  • NEWTap-to-skip. Step-by-step ghurte hoy na; shob match ek nojore dekhe bad dewa match e tap.
  • NEWNever change 🔒 preview te. “Mark Twain” list e thakle oi jaygay lock dekhay, ar Mark → Luke oi jaygay jay na. Ager moto Replace-er por jana jay na, ekhon age-i dekha jay.
  • NEWSmart suggestion chip. “3 inside longer words → Whole word” (market, marker e Mark mile jachche). Ek tap e Word mode. Match na pele “Try Smart” dey.
  • NEWPairs mode. Pair list = prottek pair er ON / OFF switch + “N matches”, Edit as text (find => with, Formatter er rules er same syntax), Paste pairs, Save as set, → Formatter ek tap. Diff preview shob ON pair ek sathe dekhay.
  • NEWRecent chips. Find khali thakle focus korlei ager pair gulo chip hoye ashe, ek tap e fill.
  • NEWRegex error line e. Find box lal, upore bhul ki ta likha. Replace button off.
  • Ager moto thakbe: Text / Word / Regex, Aa, Keep case, List, Smart, \n, Sel / Clip / swap, scope (field / selection / cursor), Sets (+ Formatter bridge), Recent pairs, Never change list, pair list + Check / Whole word, 3-level Undo, Copy / Paste result, 2-tap safety.
