6) PLAN-K ARCHITECTURE (decided; every step follows it)
  6.1 DATA MODEL (pure Java, package com.mgb.keyboard.layout, NEW; no Android):
    LayoutDef = layers. Layer ids: "en" (English), "av" (Bangলা phonetic: keys output LATIN letters that feed the phonetic buffer), "pb" (বাংলা fixed: keys output Bangla strings), "s1" "s2" "s3" (symbol pages), optional "nr" (number row) and "bot" (bottom row) as SHARED rows: a RowDef can carry shareGroup = "nr" | "bot" | "" so en / av / pb use ONE copy (edit once, all letter layers follow).
    LayerDef = list of RowDef. RowDef = heightPct (50..200, 100 = normal), shareGroup, list of KeyDef.
    KeyDef: id (stable text id, unique inside the layout), kind (CHAR | ACTION | SPACER), weight (float 0.25..8, step 0.25; row width = sum of weights, the row always fills the screen width like today), out[2] (tap text normal / shift; "" = none), label[2] (display text; "" = same as out), lp (long-press text, may be several characters or "" = none), sw[4] (swipe up / down / left / right text or action id, "" = none), action (id string when kind = ACTION: shift backspace enter space sym lang emoji globe voice tab clip comma period undo redo ... = the SAME functions the bottom row / toolbar already call), flags (bold, wide-hint, no-popup).
    SPACER = empty spot: draws nothing (or a dashed outline in the editor), types nothing, takes weight.
    MERGE (two neighbours -> one): new weight = sum; out / label / lp / sw come from the FIRST key; the SECOND key's out becomes the first's long-press if the first has none (nothing is lost silently; the editor says so). Two SPACERs merge into one SPACER. SPLIT (one key -> two): weight / 2 each (minimum 0.25 each, else refused); first keeps everything, second = SPACER the user can fill.
    MOVE = swap with neighbour (left / right inside the row), up / down = move the key into the same index of the row above / below (index clamped); ADD key before / after; DELETE key (the row must keep >= 1 key); ADD / DELETE / DUPLICATE row; row height %.
    WARNINGS (LayoutCheck, pure, returns a list of Warn{severity, keyId(s), text}): W_DUP = same non-empty tap output (case-insensitive for letters) on 2 keys of the same layer (shift state compared separately) -> keys get the WARN outline + a list "q is on 2 keys"; W_OVERLAP (lower severity) = a swipe / long-press text equals a tap output of another key in the same layer; W_MISSING = layer has no backspace / enter / space / shift / symbols key (warn only, never block); W_NARROW = weight < 0.5; W_WIDE = a row's total weight differs > 25 % from the widest row (info); W_EMPTY_ROW. Saving is NEVER blocked by a warning (user asked: "warning dibe").
    HISTORY (LayoutHistory.java): undo / redo stack of LayoutDef snapshots (max 50), pure.
  6.2 CODEC: compact tolerant text, version header "JKL1" (K4 fixes the exact grammar and may refine it; decode never throws; unknown fields ignored; fields URL-encoded like ClipList): lines  "L <layer>" / "R <heightPct> <share>" / "K <kind>,<w*100>,<out0>,<out1>,<label0>,<label1>,<lp>,<up>,<down>,<left>,<right>,<action>,<flags>".   6.1b REV 2 MODEL RULES (added by the senior review; K3 / K4 build them)
    R1 SHIFT DEFAULT: out[1] "" on a Latin letter = uppercase of out[0]; on any other text = same as out[0]. LayoutCheck compares the EFFECTIVE shift output, so "q" + auto "Q" never warns.
    R2 TEXT LIMITS by Unicode code points, never by UTF-16 units: out / swipe <= 16 code points, label <= 6 grapheme-ish chars, long-press <= 16 (a Bangla conjunct, ZWJ U+200D, ZWNJ U+200C, emoji must not be cut in half; test with "\u0995\u09CD\u09B7", "\uD83D\uDE00", ZWJ). The editor SHOWS ZWJ / ZWNJ as small visible symbols so the user can see them.
    R3 SANITISE every text field on decode AND on edit: control characters removed (only \n and \t allowed), no unpaired surrogate, trimmed length. A swipe / long-press value starting with "@" = ACTION id from a WHITELIST (@tab @undo @redo @paste @copy @cut @selall @emoji @clip @lang @caps @sym @left @right @home @end @del_word); unknown @id = ignored (never typed). This gives "swipe-up = Paste" with no new code path.
