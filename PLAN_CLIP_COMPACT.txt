PLAN_CLIP_COMPACT - compact + minimalist clipboard in 4 small steps (owner request 2026-11-17, with screenshots)
=====================================================================================================
OWNER WANTS: every existing clipboard option stays. Only the DESIGN gets compact + minimalist: more room for the copied clips, clips not cut off.
SEEN (screenshot, select mode, simple look): row 1 = ABC | Search | Done, row 2 = All / Pinned / Text / Links / Numbers, row 3 = Undo (right side, alone), then the cards, then the bottom bar (Pin / Delete / Paste / More). Cards: text cut at the top / bottom, big meta row (Aa, 62 - 21m), big checkbox.
IDEAS the owner liked (from his list + a popover screenshot of an iOS menu): (1) compact pill popover, (2) icon + short label, (3) inline accordion, (4) horizontal chip bar. Menu style to copy (own drawing, not copied art): label LEFT, icon RIGHT, thin group dividers, tick on the active choice, rounded dark card, row 40 dp, red for delete.
RULES: one step = one version = one topic. Patch only. New behaviour behind ONE pref each (default ON, OFF = exactly the version before). No existing id / pref / handler renamed. Respect clip_btn_pct, clip_list_pct, clip_lines, clip_fit, clip_card_pct.

STEP CC1 (v0.33.0) DONE (Kotlin not compiled, phone not tested)
  Top row lower (34 dp), ABC / Done narrower, Search wider, panel padding 2 dp. Pref clip_compact (default ON, needs new look). Pure numbers in typing/ClipCompact.java (+ test).
  Result: about 10 dp more list height, no change of any action.

STEP CC2 (v0.34.0) DONE (Kotlin not compiled, phone not tested) - filter row + Undo in ONE row (horizontal chip bar idea)
  Today: the filter row (pill dropdown or flat chips) and the info / Undo line are 2 rows.
  Do: Undo becomes a small icon button "undo arrow" at the END of the filter row (only when undoAvail()); the separate info line is not added in select mode (idleSel already skips it) and, in normal mode, the count moves into the title of the top row (title already shows count) so the count line can go. Messages (msg) and the "Delete all unpinned?" confirm keep their own line (they are rare and must be read).
  Where: ClipboardFeature.makeNew (the 'info line' block + the chips / pill row), new pure helper typing/ClipCompact.java: rowPlan(selOn, undo, msg, confirm) = which of the 2 rows exist (tested).
  Pref: clip_compact2 (default ON). OFF = v0.33.0 layout.
  Saves one full row (about 34 dp).

STEP CC3-A (v0.35.0) DONE (untested on phone) - slim bottom select bar. STEP CC3-B (v0.35.1) NEXT = popover for More + 3-dot menu, pref clip_pop (see PLAN_CLIP_COMPACT_CC3_two_parts.docx).
