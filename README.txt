Jabra Keyboard - personal Android keyboard (Ridmik-inspired, own code). Offline: no account, no cloud, no tracking.
Languages: English, Avro phonetic, Probhat. Panels: clipboard, novel formatter, vault, text tools, profiles, themes + Theme Studio, emoji, number pad, symbols, cursor pad, PC mode, size, settings, health check, backup / restore.
Build: push to main on GitHub. The APK appears under Releases. On the phone: app screen > Check for updates.
Docs in this folder: CHANGELOG.txt (every version, newest on top), CHECKLIST.txt (phone tests), REVERT.txt (go back to an older version),
HANDOFF_Jabra-Keyboard_<newest version>.txt (project notes for the next chat; keep ONLY the newest one).
