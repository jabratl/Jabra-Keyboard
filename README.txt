Jabra Keyboard - personal Android keyboard (Ridmik-inspired, own code). Offline: no account, no cloud, no tracking.
Languages: English, Avro phonetic, Probhat. Panels: clipboard, novel formatter, vault, text tools, profiles, themes + Theme Studio, emoji, number pad, symbols, cursor pad, PC mode, size, settings, health check, backup / restore.
Build: push to main on GitHub. The APK appears under Releases. On the phone: app screen > Check for updates.
App screen (version 0.15.9): Home with 7 pages: Typing | Look & Theme | Layout & Size | Keys & Gestures | Clipboard & Tools | Data & About | Tools & Panels. Every page is split into named sections; search, Favourites, per-row reset, "Reset this section / page" with Undo, tap a stepper number to type an exact value, theme grid + custom theme editor, toolbar editor.
Docs in this folder: CHANGELOG.txt (every version, newest on top; versions older than v0.10.0 are in docs/ARCHIVE_CHANGELOG.txt), CHECKLIST_SMOKE.txt (10-minute phone test, use this first after an update), CHECKLIST.txt (full phone tests), REVERT.txt (go back to an older version),
HANDOFF_Jabra-Keyboard_<newest version>.txt (project notes for the next chat; keep ONLY the newest one).
